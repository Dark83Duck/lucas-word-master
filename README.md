# 📚 Lucas의 단어 마스터 (Lucas Word Master)

구글 시트를 기반으로 영단어를 스마트하게 학습하고, 단어장 사진을 찍으면 **Gemini 3.5 AI Vision**이 자동으로 단어를 추출하여 구글 시트에 바로 누적 저장해 주는 단어장 웹 애플리케이션입니다.

---

## 🌟 주요 기능 (Key Features)

### 1. 📊 구글 시트 연동 단어 학습 및 테스트
- **구글 시트 자동 파싱**: A열(단어), B열(품사/형태), C열(뜻), D열(세트 구분, 예: day1) 구조의 구글 시트 데이터 로드.
- **공부하기 (단어장 모드)**: 카드로 단어 확인 및 **Web Speech API (TTS)** 기반의 정확한 미국식 영단어 발음 듣기 지원.
- **시험보기 (테스트 모드)**:
  - **단어 뜻 맞추기**: 4지선다 객관식 퀴즈
  - **스펠링 맞추기**: 한글 뜻을 보고 단어를 직접 입력하는 주관식 타이핑 퀴즈
- **오답 노트 & 다시 풀기**: 테스트 종료 후 틀린 단어만 모아서 재시험 기능 제공.

---

### 2. 📷 사진으로 단어장 만들기 (AI OCR 단어 추출)
- **🔑 사용자 지정 Gemini API Key**: 개별 키로 AI Vision을 이용합니다. 기본값은 현재 페이지에서만 사용하는 비영구 보관이며, **이 기기에서 기억**을 선택할 때만 브라우저에 저장합니다.
- **🤖 Gemini 3.5 AI Vision**: 가장 최신의 초고속·저토큰 모델인 `gemini-3.5-flash-lite` 기반으로 표 양식 및 손글씨 단어장도 완벽히 구분.
- **🖱️ 드래그 앤 드롭 (Drag & Drop)**: 탐색기에서 사진을 끌어다 놓기만 해도 즉시 업로드.
- **📚 다중 사진 일괄 추출 (Multi-file Batch)**: 여러 장의 단어장 사진(1페이지, 2페이지...)을 한 번에 올려 순차 분석 후 하나의 단어 목록으로 통합.
- **✏️ 실시간 결과 편집**: 추출된 A(단어), B(품사), C(뜻), D(세트) 데이터를 화면에서 즉시 오타 수정, 행 추가, 삭제 가능.
- **🔄 화면 초기화**: `[초기화]` 및 `[다른 사진으로 새로 추출하기]` 버튼으로 손쉽게 다음 사진 작업으로 전환.

---

### 3. 📊 구글 시트 직통 연동 & 데이터 내보내기
- **📊 구글 시트 바로 저장 (누적 추가)**: Google Apps Script 웹앱 연동 시, 사진에서 추출한 단어를 구글 시트(`시트1`) 2행부터 기존 데이터 아랫행에 **덮어쓰지 않고 계속 누적 저장**.
- **📋 클립보드 복사 (TSV)**: 구글 시트 셀 선택 후 `Ctrl+V` (or `Cmd+V`) 시 A~D열로 자동으로 나눠 들어가는 TSV 포맷 복사.
- **📥 CSV 파일 저장**: 엑셀/구글 시트 한글 깨짐 방지(UTF-8 BOM 포함) 지원.
- **🚀 앱에서 바로 학습**: 추출한 단어를 구글 시트를 거치지 않고 앱 단어장에 바로 등록해 시험 시작 가능.

## 🚀 사용 및 구글 시트 연동 가이드

### 1. 단어 학습 시작하기
1. 브라우저에서 `index.html`을 실행합니다.
2. 내 구글 시트 공유 링크(권한: `링크가 있는 모든 사용자`)를 입력하고 **[단어 데이터 불러오기]**를 클릭합니다.

### Gemini API Key 보관 및 삭제
- **기본값**: 키는 현재 페이지의 입력창과 실행 중인 OCR 메모리에서만 사용합니다. `localStorage`나 `sessionStorage`에 저장하지 않으며, 새로고침하거나 페이지를 떠나면 다시 입력합니다. 같은 페이지에서 사진을 바꾸거나 여러 장을 추출할 때는 재입력할 필요가 없습니다.
- **이 기기에서 기억**: 직접 선택하면 입력한 키와 저장 동의 표시를 `localStorage`에 저장하고 다음 방문 때 복원합니다. 선택한 상태에서 키를 수정하면 저장된 키도 갱신합니다. 실제 저장 범위는 같은 사이트의 해당 브라우저 프로필입니다.
- **기억 선택 해제**: 저장된 키와 동의 표시를 즉시 제거합니다. 입력창의 키는 현재 페이지에서 계속 사용할 수 있습니다.
- **저장된 키 즉시 삭제**: 저장된 키, 동의 표시, 현재 입력창의 키를 지웁니다. OCR 처리 중이나 결과 화면에서도 사용할 수 있습니다. 이미 시작한 OCR 요청/일괄 작업은 계속되지만, 완료 후 키를 다시 저장하지 않습니다. 이 기능은 Google에서 발급한 키 자체를 폐기하지는 않습니다.
- **기존 자동 저장 키**: 저장 동의 표시가 없는 기존 키는 첫 방문 시 영구 저장소에서 삭제하고 현재 페이지에서만 사용할 수 있도록 옮깁니다. 계속 보관하려면 기억을 직접 선택해야 합니다.
- **저장소 차단·오류**: 저장 또는 삭제 실패를 화면에 알리고 OCR은 입력한 키로 계속 사용할 수 있습니다. 삭제를 확인할 수 없다는 안내가 나오면 브라우저 설정에서 이 사이트의 데이터를 삭제하세요.
- **보안 한계**: `localStorage`는 암호화된 비밀 저장소가 아닙니다. 같은 출처에서 실행되는 스크립트(외부 라이브러리 포함)나 기기에 접근할 수 있는 사람이 키를 읽을 수 있으므로 공용 기기에서는 기억을 선택하지 마세요. 비영구 보관도 실행 중인 페이지의 스크립트로부터 키를 숨기는 기능은 아닙니다.

### 2. 구글 시트에 단어 자동 누적 저장 연동 방법 (최초 1회 1분 소요)
1. 사용 중인 구글 시트 상단 메뉴 **[확장 프로그램]** ➔ **[Apps Script]**를 클릭합니다.
2. `Code.gs` 내용에 프로젝트의 `Code.gs` 소스 코드를 붙여넣습니다.
3. 우측 상단 **[배포]** ➔ **[새 배포]** ➔ ⚙️ **'웹 앱'** 선택:
   - **다음 사용자 지정**: `나`
   - **액세스 권한이 있는 사용자**: `모든 사용자`
4. 배포 후 생성된 **웹 앱 URL**을 앱 내 **[구글 시트 자동 저장 설정 (⚙️)]**에 등록하면 사진 추출 결과가 시트에 자동 저장됩니다.

## 🧪 API Key 보관 회귀 테스트

Node.js 18 이상에서 별도 패키지 설치 없이 실행합니다. 가짜 키와 모의 OCR 응답만 사용하며 Gemini에 요청을 보내지 않습니다.

```sh
node --test tests/gemini-key-storage.test.cjs
```

브라우저 수동 확인 시나리오:

| 시나리오 | 기대 결과 |
| :--- | :--- |
| 기억을 선택하지 않고 키 입력 → 여러 사진 OCR → 화면 초기화 | OCR마다 재입력하지 않으며 두 Web Storage에 키가 저장되지 않음 |
| 위 상태에서 새로고침 또는 페이지를 떠났다가 뒤로 가기 | 입력창이 비어 있고 기억이 선택되지 않음 |
| 기억 선택 → 키 입력/수정 → 새로고침 | 저장한 키가 복원되고 기억 선택 유지 |
| 기억 해제 → OCR → 새로고침 | 해제 즉시 저장 키·동의 삭제, 현재 OCR 가능, 새로고침 후 빈 입력창 |
| 저장된 키 즉시 삭제(입력/처리 중/결과 화면 각각) | 입력창·저장 키·동의 삭제, 진행 중 OCR 완료 후에도 재저장하지 않음 |
| 동의 표시 없이 기존 `geminiApiKey`만 저장된 상태로 열기 | 기존 키는 현재 페이지에서만 사용, 영구 저장은 제거, 기억은 미선택 |
| 저장소 접근 차단 또는 저장 용량 초과 | 오류 안내, 기억 선택 자동 해제, 입력한 키로 OCR 가능 |
| 저장된 키 삭제가 실패하도록 설정 | 삭제 성공으로 표시하지 않고 사이트 데이터 삭제 안내 |
| 두 탭에서 기억된 키 사용 중 한 탭에서 삭제 | 다른 탭도 키·기억 선택 해제, 이후 입력만으로 재저장되지 않음 |
| 키 삭제 전후 시트 URL·Apps Script URL 비교 | 두 URL 설정은 유지 |
