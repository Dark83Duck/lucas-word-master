# 📚 Lucas의 단어 마스터 (Lucas Word Master)

구글 시트를 기반으로 영단어를 스마트하게 학습하고, 단어장 사진을 찍으면 **Gemini 3.5 AI Vision**이 자동으로 단어를 추출하여 구글 시트에 바로 누적 저장해 주는 단어장 웹 애플리케이션입니다.

---

## 🌟 주요 기능 (Key Features)

### 1. 📊 구글 시트 연동 단어 학습 및 테스트
- **구글 시트 자동 파싱**: A열(단어), B열(품사/형태), C열(뜻), D열(세트 구분, 예: day1) 구조의 구글 시트 데이터 로드.
- **공부하기 (단어장 모드)**: 카드로 단어 확인 및 **Web Speech API (TTS)** 기반의 정확한 미국식 영단어 발음 듣기 지원.
- **시험보기 (테스트 모드)**:
  - **단어 뜻 맞추기**: 4지선다 객관식 퀴즈
  - **스펠링 맞추기**: 한글 뜻을 보고 단어를 직접 입력하는 주관식 타이핑 퀴즈
- **오답 노트 & 다시 풀기**: 테스트 종료 후 틀린 단어만 모아서 재시험 기능 제공.

---

### 2. 📷 사진으로 단어장 만들기 (AI OCR 단어 추출)
- **🔑 사용자 지정 Gemini API Key**: 개별 Gemini API 키 입력 및 저장 기능으로 안전하고 자유로운 AI Vision 이용 지원 (기존 접근 비밀번호 입력 모달 제거).
- **🤖 Gemini 3.5 AI Vision**: 가장 최신의 초고속·저토큰 모델인 `gemini-3.5-flash-lite` 기반으로 표 양식 및 손글씨 단어장도 완벽히 구분.
- **🖱️ 드래그 앤 드롭 (Drag & Drop)**: 탐색기에서 사진을 끌어다 놓기만 해도 즉시 업로드.
- **📚 다중 사진 일괄 추출 (Multi-file Batch)**: 여러 장의 단어장 사진(1페이지, 2페이지...)을 한 번에 올려 순차 분석 후 하나의 단어 목록으로 통합.
- **✏️ 실시간 결과 편집**: 추출된 A(단어), B(품사), C(뜻), D(세트) 데이터를 화면에서 즉시 오타 수정, 행 추가, 삭제 가능.
- **🔄 화면 초기화**: `[초기화]` 및 `[다른 사진으로 새로 추출하기]` 버튼으로 손쉽게 다음 사진 작업으로 전환.

---

### 3. 📊 구글 시트 직통 연동 & 데이터 내보내기
- **📊 구글 시트 바로 저장 (누적 추가)**: Google Apps Script 웹앱 연동 시, 사진에서 추출한 단어를 구글 시트(`시트1`) 2행부터 기존 데이터 아랫행에 **덮어쓰지 않고 계속 누적 저장**.
- **📋 클립보드 복사 (TSV)**: 구글 시트 셀 선택 후 `Ctrl+V` (or `Cmd+V`) 시 A~D열로 자동으로 나눠 들어가는 TSV 포맷 복사.
- **📥 CSV 파일 저장**: 엑셀/구글 시트 한글 깨짐 방지(UTF-8 BOM 포함) 지원.
- **🚀 앱에서 바로 학습**: 추출한 단어를 구글 시트를 거치지 않고 앱 단어장에 바로 등록해 시험 시작 가능.

## 🚀 사용 및 구글 시트 연동 가이드

### 1. 단어 학습 시작하기
1. 브라우저에서 `index.html`을 실행합니다.
2. 내 구글 시트 공유 링크(권한: `링크가 있는 모든 사용자`)를 입력하고 **[단어 데이터 불러오기]**를 클릭합니다.

### 2. 구글 시트에 단어 자동 누적 저장 연동 방법 (최초 1회 1분 소요)
1. 사용 중인 구글 시트 상단 메뉴 **[확장 프로그램]** ➔ **[Apps Script]**를 클릭합니다.
2. `Code.gs` 내용에 프로젝트의 `Code.gs` 소스 코드를 붙여넣습니다.
3. 우측 상단 **[배포]** ➔ **[새 배포]** ➔ ⚙️ **'웹 앱'** 선택:
   - **다음 사용자 지정**: `나`
   - **액세스 권한이 있는 사용자**: `모든 사용자`
4. 배포 후 생성된 **웹 앱 URL**을 앱 내 **[구글 시트 자동 저장 설정 (⚙️)]**에 등록하면 사진 추출 결과가 시트에 자동 저장됩니다.

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: HTML5, Vanilla JavaScript (ES6+), CSS3
- **Styling**: Tailwind CSS (CDN), Pretendard Font
- **Icons**: Lucide Icons
- **AI Vision**: Google Gemini API (`gemini-3.5-flash-lite`)
- **Audio/TTS**: Web Speech API (`SpeechSynthesisUtterance`, `en-US`)
- **Backend / Integration**: Google Apps Script (GAS) `doPost` API
