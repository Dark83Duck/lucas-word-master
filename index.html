추출한 단어를 구글 시트(시트1) 2행부터 기존 데이터 아래에 이어 누적 저장하려면 아래 1분 설정이 필요합니다.

연동 방법 (1분 소요)

  1. 내 구글 시트 ➔ 메뉴 [확장 프로그램] ➔ [Apps Script] 클릭
  2. 기존 코드를 삭제하고 아래 버튼으로 복사한 코드를 붙여넣습니다.
  3. 우측 상단 [배포] ➔ [새 배포] ➔ ⚙️ 아이콘 ➔ '웹 앱' 선택
  4. 설정: 다음 사용자 지정: 나 / 액세스 권한: 모든 사용자 로 변경 후 [배포] 클릭
  5. 생성된 '웹 앱 URL'을 복사하여 아래 입력창에 붙여넣고 저장하세요!
